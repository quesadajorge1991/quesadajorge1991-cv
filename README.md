## 📝 Cómo usar este repositorio

Si quieres usar este diseño para tu propio CV:

1. **Fork** este repositorio
2. Edita `index.html` con tus datos personales
3. Activa GitHub Pages en **Settings → Pages** (rama `main`, carpeta `/root`)
4. Listo, tu CV estará online en `https://tu-usuario.github.io/nombre-repo/`
